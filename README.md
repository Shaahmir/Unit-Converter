# Unit Converter

A simple unit converter Android app built with **Kotlin** and **Jetpack Compose**.

This is my **first Android app**, created as a learning project while getting familiar with Kotlin, Android Studio, and Jetpack Compose.

## About the App

Unit Converter is a small and simple app for converting between commonly used units.

The app currently focuses on basic length conversions such as:

* Meters ↔ Centimeters
* Meters ↔ Kilometers
* Inches ↔ Feet
* Feet ↔ Inches
* And other simple length conversions

The goal of this project was to learn and practice Android app development rather than build a large or complex application.

## Features

* Simple single-screen interface
* One input field
* Two unit selection dropdowns
* Instant conversion result
* Light mode with custom colors
* Dark mode with custom colors
* Built using Jetpack Compose

## Built With

* **Kotlin**
* **Jetpack Compose**
* **Android Studio**
* **Gradle**

## App Structure

The app intentionally keeps the interface simple:

* One heading
* One input field
* Two dropdown menus for selecting units
* One result paragraph

There are no multiple tabs, pages, or complicated navigation flows.

## Running the Project

Clone the repository:

```bash
git clone https://github.com/Shaahmir/Unit-Converter.git
cd Unit-Converter
```

Then open the project in **Android Studio** and allow Gradle to sync.

You can also build the project from the command line.

### Windows

```powershell
.\gradlew.bat assembleDebug
```

### macOS / Linux

```bash
./gradlew assembleDebug
```
